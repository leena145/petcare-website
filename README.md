~PetCare Web Application

A full-stack PHP + MySQL web application for managing pet care services, bookings, and admin operations.

 {Features}
- User registration & login
- Pet service booking
- Admin dashboard
- Service management
- Contact form
- Voice chatbot assistant (browser-based)
- MySQL database integration

{Tech Stack}
- PHP
- MySQL
- HTML/CSS/JavaScript
- XAMPP (local development)
- InfinityFree (deployment)

 {How to Run Locally}
1. Install XAMPP
2. Place project inside htdocs
3. Import database using phpMyAdmin
4. Update config.php with DB credentials
5. Start Apache & MySQL
6. Visit localhost/project-folder
